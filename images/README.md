# Fancy Corner Online — Image Library

Keep all client-supplied product images inside this folder.

## Website collection mapping
- Mini Racer Bikes — bike product images
- Racer Cars — racing/sports car product images
- Super Bikes — premium/super-bike product images
- Vintage Cars — classic/vintage car product images
- Vintage Materials — vintage-style boxed/set materials
- Craft Materials — tulle, yarn and DIY craft material images
- Brand Logo — use the uploaded Fancy Corner Online logo image everywhere; do not redraw the logo in HTML/SVG.

The storefront references images from this folder so the same client assets are used consistently across the homepage, catalogue, cart and footer.
